은광이의 케이크 부대끼 — 음악 자동 재생 + 효과음 고정 버전
====================================================

실행 방법
1. ZIP 압축을 풀고 index.html을 여세요.
2. 브라우저가 자동재생을 허용하면 페이지가 열릴 때부터 BGM이 나옵니다.
3. 대부분의 브라우저에서는 소리 있는 자동재생을 막습니다. 이 경우 ‘게임 시작’ 등 화면을 처음 터치/클릭하는 순간 자동으로 음악이 시작됩니다.
4. 2~12페이지로 이동해도 음악은 끊기지 않으며, 끝나면 반복됩니다.

바뀐 점
- 배경음악 ON/OFF 버튼과 효과음 ON/OFF 버튼을 화면에서 완전히 제거했습니다.
- 효과음은 항상 켜져 있습니다.
- 배경음악도 사용자가 별도 음악 버튼을 누를 필요 없이 첫 클릭/터치에서 재생됩니다.
- 배경음악 볼륨은 40%, 효과음은 기존 음량을 유지했습니다.
- 기존 모든 게임 화면, 재료 조합, 결과 분기는 변경하지 않았습니다.

구성
index.html            게임 화면
style.css             디자인
script.js             게임 진행, 자동 BGM, 효과음 재생
assets/bgm.mp3        제공한 「한 사람 (inst.)」 변환 MP3
assets/sfx/*.wav      게임 효과음
assets/*.png          원본 게임 이미지

문제 해결
- 소리가 나지 않으면 컴퓨터/브라우저 탭이 음소거인지 확인하세요.
- assets/bgm.mp3 파일이 게임 폴더 안에 있는지 확인하세요.
- Safari, Chrome 등은 사용자 입력 전 소리 있는 자동재생을 제한할 수 있습니다.
- 음악 볼륨 조절: script.js의 bgm.volume = 0.40; 값을 0.0~1.0 사이로 바꿔주세요.

웹에 공개할 때는 해당 음원의 공개 사용 권한을 확인해 주세요.
